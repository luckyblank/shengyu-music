# 声屿音乐 · 设计系统

> 竞品借鉴清单见 `docs/product/netease-benchmark.md`。

> 适用于 V0 → V1.2 的所有界面。任何新增页面/面板必须从本文件取令牌，
> 禁止引入体系外的颜色或间距（封面渐变除外，见「封面体系」）。

## 0. 双主题与品牌色（V1.4 更新）

- 双主题：**深海**（青灰底 `#0d2024`，默认）与**晨雾**（云灰底 `#edf2f7`）；切换入口同前。
- **品牌强调色 = 网易红系**：深海 `#ec4141`（hover `#ff5a5a`）、晨雾 `#e03a3a`。所有可点/在播/已选状态统一走 `--accent`。
- 字体：正文 `Segoe UI Variable → Avenir Next → PingFang SC → 雅黑`；标题展示 `--font-display`（霞鹜文楷 Screen）；数字/标签 `--font-mono`。
- 青少年关怀模式字号阶梯（V1.4）**：导航 15px、曲目标题 14px、按钮 13.5px、区块标题 22px、正文 13.5px；列表行高 62px、导航项 46px。字号覆盖块位于 main.css 末尾（优先级最高）。
- **四档阴影（V1.6）**：`--shadow-1`（描边级）/ `--shadow-2`（卡片，别名 `--shadow-card`）/ `--shadow-pop`（菜单、抽屉）/ `--shadow-overlay`（搜索浮层这类大面浮层）。硬性规范：圆角上限 16px，阴影只用这四档。
- **聚焦态（V1.6）**：可输入控件用 `--brand-ring` 做「红色透明描边」代替浏览器默认 outline 方框；搜索框在此之上再叠一圈光环 `box-shadow: 0 0 0 4px var(--brand-soft)`。胶囊 hover 用 `--surface-soft-hover`（不直接用 `--surface-hover`：亮色下要变暗一档，否则胶囊会「越 hover 越亮」，看起来像被选中）。
- **遮罩 `--scrim`（V1.6）**：所有遮罩只表达「这一层在等你的操作」，不做重度压暗。遮罩一律**从顶栏下方开始**（`inset: var(--header-h) 0 var(--player-h)`）—— 顶栏的搜索框是常驻入口，抽屉打开时点它应当直接进搜索，而不是被遮罩吃掉这一下点击。

## 0-1. 双主题（V1.2 历史）

深色为主题默认；亮色主题为**暖纸色调色板**（`#efe9dc` 纸底 + 深珊瑚 `#dd5435`）。
所有界面颜色统一走语义令牌（`--wash-1/2/3`、`--line`、`--surface`、`--text-*`、`--control`），
硬编码色值只允许出现在 `base.css` 的 `:root` 与 `:root[data-theme='light']` 两块里。

- 切换入口：顶栏太阳/月亮按钮 + 设置页「界面主题」
- 状态：`settings.theme` 持久化；切换时同步窗口底色（IPC `window:theme-background`）避免 resize 闪色
- 深浅色都必须满足正文对比度 ≥ 4.5:1；珊瑚在亮底上加深以保证对比

## 2. 字体

- 正文：`Avenir Next → PingFang SC → Microsoft YaHei UI → sans-serif`（token `--font-sans`）
- 数字/标签/等宽：`SFMono-Regular → Cascadia Code → Consolas`（token `--font-mono`），用于时间、序号、格式徽标、kbd、代码路径
- 字阶（桌面 1440×900）：正文 12–13px；次级 9–10px；页面标题 `clamp(30px, 4vw, 58px)`；区块标题 20px
- 字重：正文 400–560，标题 620–650，避免 700+ 的粗黑感

## 3. 间距与圆角

- 基准 8px；页面内边距 26–34px；卡片内边距 20–24px
- 圆角分层：控件 8–12px / 卡片 14–18px / 大卡与封面 20–26px
- 列表行高：曲目行 64px，队列行 56px，导航项 42px

## 4. 封面体系（生成式封面）

无真实封面时使用 6 个确定性渐变（`CoverArt.vue`），全部衍生自主色系：

| 变体 | 渐变（145°） |
| ---- | ---- |
| `ember` | `#ef6b4f → #b93b30 → #3b1820` |
| `tide` | `#3c9cab → #236276 → #122e46` |
| `moss` | `#97a86d → #536440 → #253528` |
| `violet` | `#8a7ca5 → #554d72 → #29263f` |
| `sand` | `#d5aa72 → #9c704f → #4a342d` |
| `night` | `#6b798e → #313b4c → #171b25` |

共性装饰：噪点纹理（feTurbulence + soft-light）、双同心圆环、高光核、右下等宽字体标记「ST」。播放中封面轨道元素 8s 线性旋转。本地文件无内嵌封面时，按文件 ID 哈希落到同一组变体。

## 5. 动效

- 时长 140–240ms，缓动 `cubic-bezier(0.22, 1, 0.36, 1)`（页面入场 320–380ms）
- 交互反馈：按钮按压 `scale(0.94–0.98)`；悬浮卡片 `translateY(-5px)`；文字按钮悬浮时右箭头位移
- 持续动画（旋转封面、频谱呼吸、播放条均衡条）速率低且可读，全部遵守 `prefers-reduced-motion`
- 面板：右侧滑入（队列）、底部浮起（均衡器）、缩放淡入（菜单/对话框）

## 6. 侧栏歌单列表（V1.1 重设计）

"我的歌单"不再是紧凑的行文本，改为**卡片式列表**：

- 行高 56px（封面 38px + 上下 9px padding），行间 gap 6px，标题下方留 3px 给等宽计数
- 圆形播放入口按钮 26px，悬浮/激活时浮现；封面悬浮 scale(1.06)
- 激活项：左侧 2px 珊瑚指示条（与主导航一致）+ 亮背景
- 列表区独立滚动（右侧 6px 负边距让滚动条贴边），标题行带等宽歌单计数

## 7. 组件约定

- 图标：全部走 `AppIcon.vue`（stroke 1.8，24×24 viewBox），新增图标必须与现有圆头风格一致；不得引入 emoji 或位图图标
- 按钮四层：`primary-button`（珊瑚实底）/ `secondary-button`（描边）/ `icon-button`（无底）/ `text-button`（文字+箭头）
- 开关：统一 `.switch-track` 结构（checkbox + 轨道 + 滑块）
- 滑杆：`input[type=range]` 自定义 webkit track/thumb，进度用 `--range-progress` 渐变变量；均衡器竖滑杆用 `writing-mode: vertical-lr`
- 状态完整：hover / active / focus-visible（珊瑚 2px outline）/ disabled / loading（spinner）/ empty（唱片圆盘占位）
- 徽标：等宽字体小胶囊（格式、来源、队列数），配色限定珊瑚/绿/中性

## 8. 新增面（V1）的设计说明

- **沉浸播放页**：整屏层复用封面变体做 90px 模糊背景光晕，正文区留白对半分（左封面右歌词），歌词行 15px、激活行放大 1.06 + 加亮
- **频谱**：画布 64 柱、柱宽 2px、珊瑚→苔绿纵向渐变；无真实信号时降级为确定性呼吸波形，并用等宽小字如实标注
- **Toast**：底部居中堆叠，7px 状态圆点（绿/黄/珊瑚），毛玻璃底
- **队列**：拖拽手柄 6 点阵，拖入悬停行顶部珊瑚指示线
