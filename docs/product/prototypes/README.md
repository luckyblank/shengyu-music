# 产品原型

- `music-player-home.png`：V0 首页高保真原型，由当时 Vue 界面在 1440×900 视口下实际渲染生成，作为 V0 视觉基线。
- `music-player-home-v1.png`：V1 首页实机截图（2026-08-29），运行中的应用窗口直拍（1440×816，含真实播放条与频谱）。
- `music-player-lyrics-v1.png`：V1.1 悬浮歌词面板实机截图（2026-08-29），右侧为歌词面板（演示曲实时高亮）。
- `music-player-radio-dark-v1.png` / `music-player-radio-light-v1.png`：V1.2 网络电台页实机截图（深色/亮色双主题）。
- `music-player-discover-light-v1.png`：V1.2 亮色主题首页实机截图。
- `music-player-mini-v1.png`：V1.3 迷你播放器窗口实机截图（380×190，主窗口隐藏）。
- `music-player-desktop-lyrics-v1.png`：V1.3.2 桌面歌词悬浮窗实机截图（780×170，透明置顶）。
- `music-player-nowplaying-v1.png`：V1.3.5 黑胶唱片播放页实机截图。
- 后续重要页面建议继续使用 `music-player-<page>-v<n>.png` 命名，保留历史版本便于回溯。
