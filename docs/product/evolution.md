# 系统设计、优化与扩展建议

- 日期：2026-08-30（V1.5 交付时评估）
- 定位：给后续迭代的路线图，每项都标注优先级与理由。

## 1. 架构优化建议

| # | 建议 | 理由 | 优先级 |
| - | ---- | ---- | ------ |
| 1 | **曲库迁移 SQLite**（better-sqlite3） | 目前曲库在内存 + state.json；超过 2000 首后启动变慢、写入抖动。SQLite 支持索引搜索、事务写入、断电安全 | P1（曲库 ≥1000 首时） |
| 2 | **渲染进程拆分：音频引擎进 Worker** | 频谱计算、合成调度都在主线程，大曲库 + 动画同帧时可能掉帧。AudioWorklet/Worker 可彻底隔离 | P2 |
| 3 | **主进程服务化**：media-protocol/library/metadata 拆成独立模块目录 + 单元测试（vitest） | 当前单测缺失，元数据解析器（ID3v2 等）是最值得测的逻辑 | P2 |
| 4 | **IPC 契约生成式校验** | 目前靠 shared/ipc.ts 手工同步；引入 zod 校验入参出参可防"handle/send 不匹配"类事故（历史上发生过） | P2 |
| 5 | **播放内核状态机化** | 当前 isPlaying/loading/failed 分散在 store/engine 两处，状态机（idle/loading/playing/paused/failed）可消灭竞态 | P2 |

## 2. 播放体验优化建议

| # | 建议 | 理由 | 优先级 |
| - | ---- | ---- | ------ |
| 1 | **无缝播放（gapless）** | 整张专辑/现场专辑切歌时现在有停顿；双 Audio 元素预加载可消除 | P1 |
| 2 | **ReplayGain / 响度归一化** | 本地文件响度参差不齐，切换时忽大忽小；扫描时计算增益写入曲库 | P1 |
| 3 | **播放队列"记住我的排序"** | 目前重启后队列顺序保留但拖拽顺序未持久化到跨会话 | P2 |
| 4 | **播完自动收尾淡出**（睡眠定时已有；扩展到手动停止） | 已有 60ms 淡出，加长到 300ms 更优雅 | P3 |
| 5 | **A-B 循环 / 倍速播放** | 青少年学歌、练耳需求；引擎加 playbackRate 即可 | P3 |

## 3. 功能扩展建议（竞品对标）

| # | 功能 | 对标 | 可行性 | 优先级 |
| - | ---- | ---- | ------ | ------ |
| 1 | **本地 MV 关联** | 网易云 MV / 酷狗 MV | 关联本地 .mp4 到曲目，MV 模式优先播视频，无视频回退生成式 MV（已实现） | P1 |
| 2 | **专辑聚合页** | 网易云专辑页 | 按 album 分组卡片墙 → 专辑详情（封面/曲目/年份） | P1 |
| 3 | **歌词逐句翻译** | 网易云翻译歌词 | LRC 双语行支持（[00:12.00]原文/译文 约定格式） | P2 |
| 4 | **歌手写真墙** | 网易云歌手页 | 已实现歌手页（哈希写真横幅）；扩展：艺人详情、按艺人推荐歌单 | P2 |
| 5 | **播客/有声书模式** | 网易云播客 | 记忆各曲目进度、跳过片头、变速；当前播放器改造即可 | P3 |
| 6 | **皮肤/主题市场** | 网易云皮肤 | 当前双主题已令牌化；开放 CSS 变量覆盖 + 主题预设包 | P3 |
| 7 | **音效采样包（真蝰蛇式）** | 酷狗蝰蛇 | 当前是实时 DSP；采样卷积脉冲可更接近商业听感，需授权样本或自制 | P3 |
| 8 | **快捷键自定义** | QQ音乐/网易云 | 设置页键位表 + 拦截层改造 | P3 |
| 9 | **播放统计周报推送** | 网易云听歌报告 | 已有听歌报告页；扩展：每周一启动时弹送 | P3 |
| 10 | **云同步** | 网易云云盘 | 无账号体系前不做；需要后端与鉴权，超出本地应用范畴 | 不做（V3） |

## 4. 已发现的债（诚实清单）

- main.css 超过 3000 行且存在多轮视觉覆盖块堆叠（晨雾/深海 refresh、青少年关怀模式、V1.5 页面），建议按"基础 → 主题 → 覆盖"分层拆分文件（base / layout / pages / panels / overrides）。
- 历史 HMR 长会话造成过"面板打不开/关不掉"类假象，验收务必全新启动。
- 队列拖拽仅作用于待播区；"已播放"区不可重排（有意，但文档未注明）。
- 生成式 MV 是程序可视化，不是真实 MV 视频（已在界面标注"声屿 MV"，文档如实说明）。

## 5. 建议的 V1.6 范围（推荐方案）

按优先级：**本地 MV 关联 → 专辑聚合页 → gapless 播放 → ReplayGain → 曲库 SQLite**。
