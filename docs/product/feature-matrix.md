- 「播放/暂停」从**假计时器**改为真实音频时钟；进度条拖动真正改变播放位置。
- 播放条新增：迷你频谱、静音、均衡器开关、队列数量徽标、本地文件格式徽标。
- 侧边栏歌单从"点击即播放"改为"点击进入歌单详情"，悬停出现播放按钮。
- 搜索与曲库列表覆盖本地曲目（V0 只有 6 首演示曲）。
- 新增页面：歌单详情、最近播放、设置；新增面板：沉浸播放页、均衡器、确认对话框、Toast。

## 已知限制（诚实清单）

- 生成式演示音源是**环境音乐**，无演唱；歌词为演示用原创文本。
- 在线音源需要联网；FreePD 为 CC0 公有领域（可商用无需署名），SoundHelix 为演示用音源（不可商用）。
- 网络电台为海外公播流，**受网络环境限制**（国内网络下通常无法连接，页面已如实标注）；电台为直连播放，不经过均衡器、音效与真实频谱。
- 音效链是实时 DSP（非采样包络），效果偏"氛围化"，与商业播放器的蝰蛇音效（卷积采样）听感不同。
- 演示曲的卡拉OK逐字时间为均匀分布（无真实演唱录音），仅作效果演示。
- WMA 依赖系统解码器，部分环境可能无法播放。
- 曲库为内存 + JSON 持久化，超过数千首时建议迁移 SQLite（V2 计划）。
- 无 ReplayGain 音量归一化，不同来源响度可能有差异。
- 队列拖拽仅作用于待播区（正在播放之后的曲目）。
- 热门搜索的"热度趋势"需要**跨天快照**才有意义：本地榜基于播放次数/收藏/导入时间，只有累计到一个自然日以上的快照后才能显示升/降，首日一律标"新上榜"，不做假趋势。
- 搜索是**本地检索**（曲库 + 歌单 + 艺人 + 在线/电台元数据），没有在线曲库检索能力；"猜你喜欢"是本地信号聚合，不是服务端推荐算法。
- 搜索浮层高度自适应当前窗口：工作区高度不足时取 `min(680px, 可用高度 - 26px)`（例如 767px 高的窗口里浮层实际约 574px，内容纵向滚动）。
- 推荐页的卡片文案（今日推荐 / 私人雷达 / 心情歌单 / 华语精选 / 新歌速递 / 睡前音乐）为 1:1 沿用设计稿措辞，取数是近似映射：新歌速递取在线榜单前列切片、华语精选按曲名/艺人是否含中日韩字符启发式筛选、睡前音乐取生成曲 bpm < 90；「心情歌单」等依赖联网的栏目在断网时退化为本地曲目。
- 推荐页头图与卡片用的是随包的 6 张内置照片（真实图片，非渐变占位），不是设计稿里的实拍图库：版式一致，画面不同。
- 情绪标签是纯文字胶囊（未自造图标），点击映射到在线榜的**风格键**，不是服务端情绪模型；同一风格可对应多个情绪词，选中态按词判定。
- 头图标题按日期在 3 组文案间轮换，设计稿的那一句只在部分日期出现。
- 播放历史累计较久（次数差距大）时，推荐歌曲的前几行在「换一换」后可能不变 —— 是权重压制了随机扰动，不是按钮失效。
- 已知缺陷（V1.5.1 起存在，与搜索无关）：`library.ts` 持久化时把响应式代理直接交给 `contextBridge`，一旦生成过排行榜快照，曲库/收藏/最近播放的写入会抛 `could not be cloned` 而静默失败（设置类补丁不受影响）。修法是一行结构化展开，建议随 v1.6 一并处理。
