# 声屿音乐播放器：统一产品与技术规划

## 1. 产品定位

“声屿”是一个桌面优先的音乐播放器。当前版本先验证三件事：快速发现音乐、低干扰浏览、持续可见的播放控制。产品结构参考成熟音乐客户端的通用范式，但不复制网易云音乐或酷狗音乐的品牌资产。

当前目录中的歌曲、歌手和歌单均为原型演示数据，不代表真实版权曲库。

## 2. 版本范围

### V0：界面与核心交互（✅ 已完成）

- 发现音乐：首页主推荐、精选歌单、最近常听。
- 全局搜索：按歌曲、歌手、专辑、歌单关键词过滤。
- 个人音乐：音乐库与“我喜欢”列表。
- 播放体验：播放/暂停、上/下一首、进度、音量、随机、循环。
- 队列管理：右侧播放队列与当前播放状态。
- 窗口体验：桌面端最小尺寸、固定底部播放条、滚动内容区。

V0 的播放器控制为交互原型状态，未绑定真实音频。

### V1：可用播放器（✅ 已完成，2026-08-29）

- 真实音频播放：本地文件 + 生成式演示音源，真实进度/拖动/结束切歌。
- 本地文件/文件夹导入（含拖放），标签与内嵌封面解析，时长探测，失效清理。
- 播放状态持久化（音量/模式/收藏/歌单/曲库/EQ/进度），启动恢复不自动出声。
- 沉浸播放页：大封面、实时频谱、逐行歌词（.lrc 侧车 + 演示曲内置）。
- 队列重做：下一首播放、拖拽排序、已播放与最近播放。
- 歌单 CRUD 与详情页；5 段均衡器与预设；睡眠定时器。
- 桌面集成：无边框窗口、系统托盘、全局媒体键、应用内快捷键、单实例锁。
- 真实空状态、加载状态、错误重试与 Toast 反馈。

完整功能清单与状态见 `docs/product/feature-matrix.md`，
实施计划见 `plan/2026-08-29-real-playback-v1.md`，
技术细节见 `docs/tech/audio-engine.md` 与 `docs/tech/ipc-contract.md`。

### V2：音乐管理（⬜ 未开始）

- 歌单拖拽排序、曲库索引与标签/封面编辑。
- 迷你播放器窗口、桌面歌词、更多快捷键自定义。
- 数据规模增长后迁移 SQLite（当前 JSON 足够）。

### V3：在线服务（⬜ 未开始，需合法授权）

- 接入合法授权的音乐 API。
- 账号同步、个性推荐、评论或社区能力。
- 下载、离线与多设备进度同步。

## 4. 前端分层

```text
src/shared/ipc.ts            # 主/渲染共用 IPC 契约（通道 + 类型）
src/main
├─ index.ts                  # 生命周期、窗口、托盘、媒体键、IPC 注册
├─ media-protocol.ts         # shengyu-media:// 流式协议（Range/白名单/CORS）
├─ metadata.ts               # ID3v2 / FLAC / MP4 / WAV 标签与内嵌封面
├─ library.ts                # 文件/文件夹扫描、歌词侧车
└─ state-store.ts            # userData/state.json（原子写 + 防抖）

src/preload/index.ts         # window.shengyu 类型化桥

src/renderer/src
├─ services
│  ├─ audio-engine.ts        # AudioContext、EQ、分析器、事件总线
│  ├─ synth-source.ts        # 生成式音源（确定性调度）
│  ├─ media-source.ts        # 本地文件音源（静音自检降级）
│  └─ lrc.ts                 # LRC 解析
├─ stores                    # player / library / ui（reactive 单例）
├─ components                # PlayerBar / TrackList / QueuePanel / LyricsPane …
└─ App.vue                   # 页面编排
```

约束：组件不直接访问 IPC，统一走 store；store 不直接碰 DOM 音频，统一走 audio-engine。

## 5. 模块边界与状态

| 模块     | 职责                               | 落点                     | 状态 |
| -------- | ---------------------------------- | ------------------------ | ---- |
| 播放引擎 | 音频加载、缓冲、播放模式、设备输出 | `services/audio-engine`  | ✅   |
| 曲库服务 | 搜索、歌曲详情、推荐、歌单         | `stores/library` + 演示数据 | ✅（V1 本地曲库） |
| 本地音乐 | 扫描目录、元数据、封面提取         | Electron main + IPC      | ✅   |
| 歌词系统 | 时间轴、逐字歌词、桌面歌词         | `services/lrc` + 侧车     | ✅（桌面歌词留 V2） |
| 持久化   | 设置、播放历史、缓存               | JSON + IPC（SQLite 留 V2） | ✅   |
| 用户系统 | 登录、收藏、歌单同步、会员状态     | `services/account`       | ⬜ V3 |

## 6. 数据契约

- `Track`：唯一 ID、标题、艺人、专辑、时长、封面（生成变体或协议 URL）、来源（demo/local）、音源地址、歌词侧车、合成配方（演示曲）。
- `Playlist`：唯一 ID、名称、描述、歌曲 ID 列表、封面、来源、更新时间。
- `PlaybackState`：当前歌曲、队列、进度、音量、播放模式、加载状态、错误。
- `UserLibrary`：收藏歌曲、创建歌单、最近播放。
- `AppState`（state.json）：以上全部 + 均衡器 + 设置。

## 7. 设计系统

- 主背景：`#101215`；内容层：`#15181c` / `#20242a`。
- 主文字：`#f5f1e9`；次级文字：`#999994`。
- 唯一主强调色：`#ef6b4f`；状态成功色：`#a3b56e`。
- 间距：8px 基准；圆角按 10/12/18/26px 分层。
- 动效：160–420ms；遵循 `prefers-reduced-motion`。
- 尺寸基准：1440×900；最小窗口：1040×720。

完整令牌与组件约定见 `docs/product/design-system.md`。
