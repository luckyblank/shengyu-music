# 网易云音乐竞品分析与设计借鉴

- 日期：2026-08-30
- 目标：面向青少年的企业级桌面音乐播放器
- 原则：借鉴"好用的设计"，不复刻品牌资产（网易云红色仅为色彩参考，应用名/标识保持"声屿"）

## 1. 竞品分析：网易云音乐桌面版的好用设计

| # | 设计 | 好在哪 | 我们的落地 |
| - | ---- | ------ | ---------- |
| 1 | **品牌红强调色** | 全界面只有一个强调色，所有"可点、在播、已选"状态统一成红色，认知零成本 | `--accent` 切换为网易红系（深海 #ec4141 / 晨雾 #e03a3a），全组件自动跟随 |
| 2 | **大字关怀模式** | 面向青少年/老年用户的正文字号整体放大，行高加大，不牺牲密度 | 新增"青少年关怀模式"字号覆盖块：导航 15px、曲目标题 14px、按钮 13.5px、面板同步加大 |
| 3 | **侧边栏激活项红底白字** | 当前所在页面一眼可辨，不需要小圆点/下划线 | `.nav-item.active` 红底白字 + 红色投影（沿用现有实现，颜色自动切换） |
| 4 | **播放条三段式** | 左=封面+歌名（悬停红字）+喜欢；中=控制+进度；右=歌词/音量/队列（带数量角标） | 已对齐；歌名悬停变红、队列按钮带曲目数红色角标 |
| 5 | **队列面板** | 默认收起，点击才展开；有统计（总时长/首数）、清空、拖拽排序 | 已对齐；新增**启动强制收起**（hydrateUi 里 closeAllPanels） |
| 6 | **悬浮播放按钮** | 歌单卡片悬停时封面右下角浮现圆形播放键，平时界面干净 | 已对齐（.card-play 悬浮显现，红色 + 按压涟漪） |
| 7 | **实时歌词** | 歌词面板逐行滚动 + 当前行高亮 + 点击跳转 | 已对齐并加强：逐字卡拉OK三态着色、颜色自定义、桌面歌词悬浮窗 |
| 8 | **任务栏集成** | 缩略图悬停控制 + 进度条 | 已对齐（移除覆盖小图标，保留进度条与三键控制） |
| 9 | **音效与均衡器** | 一键音效（3D/重低音/现场等）+ 手动均衡 | 已对齐（4 预设实时 DSP + 5 段均衡） |
| 10 | **榜单** | 数据驱动的本地榜单（热播/收藏/新歌） | 已对齐 |
| 11 | **状态持久化** | 音量/模式/进度/收藏重启还原 | 已对齐 |
| 12 | **空状态引导** | 空列表给行动指引而非空白 | 已对齐（"导入音乐""去听几首歌"等引导文案） |

## 2. 设计决策（本次验收版）

- **色彩**：深海主题（青灰底 #0d2024）与晨雾主题（云灰底 #edf2f7）双主题；强调色统一网易红系。
- **排版**：正文基准 13.5–15px（青少年关怀模式），标题使用霞鹜文楷（--font-display），数字/标签等宽。
- **节奏**：卡片圆角 15–20px、控件 11–13px、圆形播放键 50%；行高 44–62px 保证点击目标。
- **动效**：160–240ms、cubic-bezier(0.22,1,0.36,1)；播放键按压涟漪；遵循 prefers-reduced-motion。
- **克制**：每屏 ≤ 1 个强调色动作；列表只保留必要列（#/封面/标题/专辑/来源/收藏/时长/更多）；面板互斥。

## 3. 有意不做（保持差异化，避免"杂乱无章"）

- 不复制网易云的评论区、动态、云盘、商城——超出播放器职责。
- 不做广告位与营销弹层。
- 不把"在线"来源混入本地曲库默认视图（需筛选或搜索）。
