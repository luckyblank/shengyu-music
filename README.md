<h1 align="center">声屿音乐</h1>

<p align="center">基于 Electron + Vue3 + TypeScript 的桌面音乐播放器（electron-vite 构建）</p>

## 功能

- **真实播放**：本地音频文件（MP3/FLAC/WAV/M4A/OGG…）、6 首开箱即响的生成式演示音源（纯 Web Audio 程序化合成，零版权、零体积）、在线直链音源（FreePD CC0 公有领域 + SoundHelix 演示曲）
- **网络电台**：6 路公播流（SomaFM · Radio Paradise），LIVE 播放模式；海外流受网络环境限制
- **双主题**：深色（默认）与亮色暖纸调色板，顶栏一键切换，窗口底色同步
- **本地曲库**：文件/文件夹/拖放导入，ID3v2/FLAC/MP4/WAV 标签解析，内嵌封面提取，失效文件自动清理
- **沉浸体验**：大封面播放页、实时频谱、逐行歌词（.lrc 侧车 + 演示曲内置 + 悬浮歌词面板 + 任意曲目手动挂载）
- **队列与歌单**：下一首播放、拖拽排序、已播放/最近播放（可清空）、歌单增删改查
- **声音整形**：5 段均衡器 + 5 预设、音量淡入淡出、滚轮调音量、睡眠定时器
- **桌面集成**：无边框窗口、系统托盘、全局媒体键、系统媒体浮窗（SMTC）、应用内快捷键、状态持久化与启动恢复
- **安全**：本地音频经 `shengyu-media://` 协议（目录白名单 + Range 支持 + CORS）流式供给渲染层

## 开发

```bash
$ npm install
$ npm run dev        # 开发（含主进程/预加载热重载）
$ npm run typecheck  # 类型检查
$ npm run lint       # ESLint + Prettier
$ npm run build      # 构建
$ npm run build:win  # 打包 Windows 安装包
```

## 快捷键

空格 播放/暂停 · ←/→ 上一首/下一首 · ↑/↓ 音量 · M 静音 · L 收藏 · Q 队列 · N 播放页 · E 均衡器 · Ctrl+K 搜索 · F11 全屏
